## Gotchas the next agent MUST know (still current)
- **Dev server: port 3002** (`npm run dev`). Restart after big changes (HMR + turbopack cache can go
  stale — twice this session a stale `.next` needed `rm -rf .next`). Log: `/tmp/devserver.log`.
- **Build is the gate:** `npm run build`. Next 16 turbopack build **doesn't print per-route sizes**; to
  judge bundle/static-vs-dynamic, read the route table (○ = static) or measure with Playwright against
  `next start`. `tsc --noEmit` has pre-existing `@syscore`/`YT` noise — filter to changed files.
- **e2e:** `node tests/in-place-editor.e2e.mjs` (39 checks; Playwright imported by absolute path from the
  sibling beta repo — see top of the file). Data-layer tests: `npx tsx --conditions react-server
  tests/*.test.ts`. **No `npm test` script** — run files directly.
- **Auth is client-resolved** via `GET /api/studio/me` (keeps marketing pages static even with
  `STUDIO_AUTH_TOKEN` set). The pencil/overlay gate is **visibility-only**; the real security boundary is
  the mutating API routes (`publish`/`merge`/`close`), which all 401 server-side. `isStudioAuthed()`
  returns true in dev when the token is unset.
- **Enter/exit edit is a HARD navigation** (`location.assign(?edit=1)`) so the landing's `useMemo([])`
  Lenis/GSAP freeze re-engages. Don't make it a soft client nav.
- **Styling applies via CSS variables** (`var(--color-<token>)`), never a Tailwind class — Tailwind v4
  won't generate a class that isn't literally in source. New colors must be added as `--color-*` tokens in
  `app/globals.css` first, then to `lib/content/colors.ts`.
